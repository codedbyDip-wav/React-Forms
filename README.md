# React Forms

A collection of React form assignments created as part of my **BSc CSIT** coursework.

This project demonstrates the use of **React**, **JavaScript**, **CSS**, and React state management to create interactive and user-friendly forms.

## 📋 Forms Included

### 1. Employee Registration Form

A form for collecting employee information such as:

* Employee Name
* Email
* Phone Number
* Address
* Department
* Position
* Other employee details

### 2. Product Creation Form

A form for entering and managing product information, including:

* Product Name
* Category
* Price
* Quantity
* Description
* Product details

### 3. College Event Registration Form

A registration form designed for college events, including:

* Student Name
* Email
* Contact Number
* Event Selection
* College/Program details
* Registration information

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm
* Git

### Clone the Repository

```bash
git clone https://github.com/codedbyDip-wav/React-Forms.git
```

### Navigate to the Project

```bash
cd React-Forms
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

The application will then be available at the local URL shown in your terminal, usually:

```text
http://localhost:5173
```
